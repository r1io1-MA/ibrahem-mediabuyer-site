# ibrahem-mediabuyer.com

موقعك كاملًا. Netlify يبنيه تلقائيًا كل ما يحصل تغيير هنا.

## كتابة مقال جديد
1. افتح https://ibrahem-mediabuyer.com/admin/
2. ادخل بـ **Sign In Using Access Token** (أول مرة بس).
3. المقالات ← New. اكتب النسخة العربي، وبعدين بدّل لـ EN واكتب الإنجليزي (أو سيبها لو مقال بلغة واحدة).
4. اكتب "رابط المقال" بحروف إنجليزي صغيرة وشرطات، مثل `ramadan-ads-guide`.
5. Save / Publish. بعد دقيقة تقريبًا المقال يظهر في الموقع، وفي القائمة الجانبية، وصفحة المصادر، والصفحة الرئيسية، وخريطة الموقع.

لو عايز تخبي مقال من غير ما تمسحه: علّم على "مسودة".

## الملفات
- `content/articles/ar` و `content/articles/en` المقالات (لوحة التحكم بتكتب هنا)
- `cases.py` دراسات الحالة · `tool.py` و `roi.py` الحاسبات · `drawer.py` القائمة الجانبية
- `src/home.html` الصفحة الرئيسية · `static/` الصور والأيقونات والتنسيق ولوحة التحكم
- `build.py` بيبني كل حاجة في فولدر `site`

## تشغيل محلي (اختياري)
    pip install -r requirements.txt
    python3 build.py
